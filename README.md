# The Age Of Capital

Jeu de stratégie / simulation historique **1750–1950** sur la naissance et le développement du capitalisme : économie spatiale sur grille de tiles, firmes autonomes, concentration capitaliste émergente, puis couche politique avec des personnages autonomes dont le joueur n'est qu'un parmi d'autres.

Inspirations : Victoria 3, Songs of Syx, RimWorld. Distribution visée : Steam. Licence : Apache 2.0.

## État

**Phase POC** : simulation économique autonome sur une carte 200×200, une ville, un maire. Le monde vit sans le joueur.

## Stack

Electron · Vue 3 · PixiJS · moteur de simulation en Rust (napi-rs) · SQLite.
